# CookLens AI skills

Các skill dưới đây được dùng cho `ai/` của CookLens:

- `langgraph-fundamentals`: graph có state, routing, persistence và error handling.
- `langchain-rag`: ingestion, retrieval và grounded response.
- `langchain-dependencies`: dependency/version management cho LangChain và LangGraph.
- `hf-cli`: thao tác với Hugging Face models/datasets khi được yêu cầu.
- `verification-before-completion`: kiểm tra trước khi báo hoàn thành.

Các quyết định đặc thù CookLens (taxonomy, metadata filter, API boundary và state) được ưu tiên theo [`../../docs/technical-architecture.md`](../../docs/technical-architecture.md).
