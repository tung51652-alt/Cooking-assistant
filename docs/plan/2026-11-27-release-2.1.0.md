# Phát hành 2.1.0

PR [#64](https://github.com/tung51652-alt/Cooking-assistant/pull/64) đưa `develop` vào `main`.

## Phạm vi

- Màn hình Trợ lý gộp xác nhận món từ ảnh, chọn món trong danh mục và tiếp tục phiên trên web và Expo ([#55](https://github.com/tung51652-alt/Cooking-assistant/issues/55), [#63](https://github.com/tung51652-alt/Cooking-assistant/pull/63)).
- Corpus `cooklens-recipes-v3` với 90 công thức ([#60](https://github.com/tung51652-alt/Cooking-assistant/pull/60)).
- Ngưỡng nhận diện 65% và chọn món theo tên khi ảnh bị từ chối ([#49](https://github.com/tung51652-alt/Cooking-assistant/issues/49)).
- Sửa UX Android/web, ghi công nguồn và hướng dẫn cài đặt trợ lý (#30–#54).

## Chuẩn bị source

- [ ] Đồng bộ version `2.1.0`: tag mặc định trong `compose.yaml`, `backend/pom.xml`, `frontend`/`mobile` package và lockfile, `mobile/app.json`.

## Nghiệm thu candidate

- [ ] Push `v2.1.0-rc.N` trên commit `main`; workflow candidate qua smoke, pull ẩn danh, CV, flow 30 ảnh và retrieval v3.
- [ ] Chạy đủ 50 câu đánh giá trợ lý với Gemini trên candidate và human review, hoặc ghi rõ quyết định hoãn tiếp.
- [ ] Bổ sung ảnh cho 4 ca Docker cần ảnh ngoài danh mục hoặc nhiều món.
- [ ] Web desktop và mobile: Bún đậu mắm tôm (một công thức), Phở (nhiều công thức), tìm rỗng, lỗi tra cứu, mở/đóng chi tiết,
  đổi công thức, tải lại để khôi phục phiên, khung nhập khi bàn phím mở.
- [ ] Android 10+ qua Expo Go SDK 58 trên thiết bị thật, ghi máy và phiên bản:

| Ca | Kỳ vọng |
| --- | --- |
| Ảnh → công thức → hỏi đáp → bắt đầu → bước tiếp/trước → kết thúc | Đúng công thức và số bước, kết thúc rõ ràng |
| Chọn món theo tên khi ảnh bị từ chối | Vào được Trợ lý với đúng món |
| Nhấn nhanh hoặc mất phản hồi | Một thao tác; retry giữ operation ID |
| Back hoặc chuyển nền khi đang tải | Bỏ response cũ, khi trở lại chỉ đọc trạng thái |
| Đóng và mở lại Expo Go | Khôi phục phiên đã lưu |
| Mất mạng, 409, 404, 410 | Thử lại, tải lại trạng thái hoặc tạo phiên mới phù hợp |
| Chữ lớn, TalkBack, safe area, quyền camera, HEIC | Điều khiển dễ dùng, luồng ảnh giữ hành vi |
