# Tài liệu CookLens

Mỗi chủ đề có một tài liệu chính:

| Tài liệu | Nội dung |
| --- | --- |
| [product.md](product.md) | Chức năng, luồng sử dụng và giới hạn |
| [architecture.md](architecture.md) | Service, dữ liệu, model, trợ lý và giới hạn runtime |
| [contracts/mvp-v1.md](contracts/mvp-v1.md) | API public, phiên trợ lý, lỗi và timeout |
| [development.md](development.md) | Môi trường, build từ source và quy trình gửi PR |
| [deployment.md](deployment.md) | Chạy Docker, cấu hình trợ lý, backup, nâng cấp và phát hành |
| [testing.md](testing.md) | Các lớp kiểm thử, lệnh chạy và tiêu chí đạt |
| [acceptance.md](acceptance.md) | Kết quả nghiệm thu, chỉ số và giới hạn đo |
| [WORKFLOW.md](WORKFLOW.md) | Quy ước làm việc, tài liệu và Git |
| [plan/](plan/README.md) | Công việc đang mở |

Khi đổi chức năng, cập nhật tài liệu chủ đề tương ứng và [CHANGELOG](../CHANGELOG.md).
Kế hoạch chỉ mô tả việc còn mở; kết quả đã kiểm chứng ghi trong `acceptance.md`.
Không đưa dataset, trọng số, secret, log thô, ảnh chụp kiểm chứng hoặc build output vào docs.
