# Backend agent resources

Thư mục này là bản đổi tên của bộ `.claude` nguồn thành `.agent` cho CookLens.

| Nhóm | Trạng thái trong CookLens |
| --- | --- |
| `skills/spring-boot`, `skills/jpa-patterns`, `agents/spring-boot-engineer` | Áp dụng cho Java 21, Spring Boot 3.x, Maven và Spring Data JPA backend. |
| `skills/code-quality`, `design-patterns`, `logging-patterns` | Áp dụng; ưu tiên convention hiện có của Spring Boot module. |
| `agents/code-reviewer`, `security-engineer`, `docker-expert`, `devops-engineer`, `kubernetes-specialist` | Dùng khi nhiệm vụ phù hợp; Kubernetes không thuộc MVP mặc định. |

Quy ước vận hành CookLens nằm trong [WORKFLOW.md](WORKFLOW.md).
